# Aspan

Жеке Flutter ауа райы жобасы. Package атауы: aspan. Басқа жергілікті жобаға тәуелділігі жоқ.

Іске қосу:

```sh
flutter pub get
flutter run
```

Бастапқы экран — белгіленген демо. Нақты болжам үшін қаланы іздеңіз. Жаңарту батырмасы соңғы қаланың болжамын қайта жүктейді. Интернет қажет. Жеке API кілті қажет емес.

Деректер: [Open-Meteo](https://open-meteo.com/), қала іздеу: [Geocoding API](https://open-meteo.com/en/docs/geocoding-api).

Тексеру: flutter analyze және екі widget тесті өтті. Нақты желілік сұрау құрылғыда тексерілмеді.
